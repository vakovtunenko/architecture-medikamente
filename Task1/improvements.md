# Список улучшений

## Способы защиты данных

### Персональные данные (ПДн)
**Список данных**:
- ФИО
- Дата рождения
- Контактные данные (телефон, email)
- Паспортные данные
- Адрес проживания/прописки
- Место работы/учёбы
- Сканы и другие формы документов

**Способы защиты**:
- Шифрование - для защиты данных при хранении и передаче
- Обезличивание (кроме сканов) - для аналитических целей, чтобы данные не могли быть напрямую связаны с конкретным пациентом

### Медицинские данные
**Список данных**:
- История болезней
- Результаты анализов
- Диагнозы
- Назначенное лечение
- Медицинские изображения (рентген, УЗИ и т.д.)

**Способы защиты**:
- Шифрование - для защиты данных при хранении и передаче
- Обезличивание (кроме изображений) - для исследований и аналитических целей, чтобы данные не могли быть напрямую связаны с конкретным пациентом

### Финансовые данные
- Реквизиты договоров
- Данные платежей
- Страховая информация

**Способы защиты**:
- Шифрование - для защиты данных при хранении и передаче
- Обфускация - можно использовать для частичного скрытия данных при отображении
- Обезличивание - для аналитики и отчетности

### Бухгалтерские данные
- Данные о платежах
- Данные о сотрудниках
- Данные о ЗП и налогах

**Способы защиты**:
- Шифрование - для защиты данных при хранении и передаче
- Обезличивание - для аналитики и отчетности

### Складские данные
- Информация о ТМЦ
- Информация о закупках

**Способы защиты**:
- Шифрование - для защиты данных при хранении и передаче

### Служебные данные
- Логины/пароли сотрудников
- Внутренняя переписка
- Отчеты по деятельности

**Способы защиты**:
Шифрование - для защиты данных при хранении и передаче
Обфускация (кроме паролей) - для скрытия чувствительных данных при необходимости

## Тегирование

### Список тегов
#### Персональные данные (ПДн)
- Весь список данных (см выше) - `PII`

#### Медицинские данные
- История болезней - `MedicalHistory`
- Результаты анализов - `MedicalResults`
- Диагнозы - `Diagnosis`
- Назначенное лечение - `Treatment`
- Медицинские изображения - `MedicalImages`

#### Финансовые данные
- Реквизиты договоров - `FinancialContracts`
- Данные платежей - `PaymentInfo`
- Страховая информация - `InsuranceInfo`

#### Бухгалтерские данные
- Данные о ЗП - `Payroll`
- Данные о налогах - `TaxInfo`
- Данные о сотрудниках - `EmployeeData`

#### Складские данные
- Информация о ТМЦ - `Inventory`
- Информация о закупках - `Procurement`

#### Служебные данные
- Логины/пароли `Credentials`
- Внутренняя переписка `InternalComms`
- Отчеты по деятельности `ActivityReports`

### Механизм тегирования
Теги проставляются при создании новых данных в файлах, модулях 1С и тд. Например, когда происходит регистрация нового пациента - к его ПДн добавляется тег.

Продвинутые инструменты для тегирования использоваться не будут - нет ни опыта, ни компетенций, ни платформы, ни денег, да и масштаб компании для использования продвинутых инструментов совершенно не тот, даже если она придет к целевому виду 

Для компании вполне достаточно будет использовать простые самописные инструменты - макросы в excel, доработать 1С, скрипты. В дальнейшем же, когда компания придет к целевому виду - можно будет самостоятельно реализовать не особо сложное решение для автоматического тегирования.

В случае необходимости или если данные не могут быть автоматически классифицированы возможно ручное проставление/изменение тегов.
